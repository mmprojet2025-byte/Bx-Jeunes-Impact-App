# Bx-Jeunes Impact App

## Description

Application web/mobile pour l’ASBL Bx-Jeunes Impact.

Cette application permet de centraliser :
- les activités
- les groupes
- les membres
- les projets des jeunes

## Objectif

Faciliter l’organisation interne et améliorer la participation des jeunes.

## Technologies

### Frontend
- Dart
- Flutter

### Backend
- Java
- Spring Boot
- Spring Security

### API
- REST
- JSON

### Authentification
- JWT
- OAuth2

### Base de données
- MySQL / PostgreSQL

## Structure du projet

- frontend-flutter : application Flutter
- backend-spring : API backend
- database : scripts SQL
- docs : documentation
- figma-miro : maquettes et idées
